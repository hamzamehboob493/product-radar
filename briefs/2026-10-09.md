### Card 1. Shopify script-tag sunset checker · 67/100 · VALIDATE

- **Track:** Micro · **Sector:** E-commerce
- **What it is:** Paste a store URL, see which scripts are still injected through script tags, which app added each one, and whether that app has moved to an app embed. Agencies get bulk reports for all client stores, re-checked weekly until 1 Mar 2027.
- **Who pays:** Shopify agencies and freelancers (5 to 200 client stores), then larger single merchants; US, UK, EU, AU.
- **The problem:** [F] Script tags stop running on storefronts on 1 Mar 2027 ([changelog](https://shopify.dev/changelog/online-store-script-tags-deprecation)). [F] No admin page lists affected apps; Shopify staff said on 27 Sep the 1 Oct merchant install warning is not shipping ([forum](https://community.shopify.dev/t/deprecation-script-tags-will-stop-running-on-march-1-2027/37108)). [F] On Tap Group: "There is no single dashboard in Shopify admin that lists all apps using script tags" ([On Tap, 4 Sep 2026](https://www.ontapgroup.com/blog/shopify-script-tags-die-in-6-months)).
- **Why now:** Hard cutoff 1 Mar 2027; failure is silent (widgets and tracking vanish).
- **Market:** Number of stores still using script tags [U]; number of affected apps [U] ("thousands" is On Tap's claim).
- **Money already flowing:** Five cleaner apps priced $4.99 to $49/month, all 0 reviews [F]; agencies sell paid audits (On Tap, zectox) [F].
- **Competitors:** Script Scan (free to $14.99/mo), AppAudit (free to $49/mo agency, reads script tags), ThemeSweep ($9.99 to $39.99/mo), Residue ($49/yr) [F]; none is about the deadline.
- **Our angle:** The only tool built around the cutoff, free without installing, with app-to-replacement mapping.
- **Build:** Easy · 4 engineer-days · Node, Postgres, PDF · hardest: reliable app attribution from script domains · 4 h/month [E].
- **Pricing [E]:** Free single check; $29 store report; $79/month agency (50 stores).
- **Validation:** 5 days, under $100. Go: 150+ checks, 30%+ of stores show a script tag, 3+ agency pre-orders or 10 paid reports.
- **Risks:** Shopify ships its own merchant list; detection method may not work (test day 1).
- **Confidence:** Medium.
