### 1. SMTP AUTH multi-tenant usage audit for MSPs · 66/100 · VALIDATE (card 1 of 2)
**Track:** Bigger build (build 1 to 4 weeks, launch by day 30) · **Sector:** Security and IT for MSPs
**What it is:** A tool the MSP runs on its own machine that lists, per client tenant, which printer, ERP or app still sends mail with basic SMTP AUTH, with a fix plan and a client-ready report.
**Who pays:** MSPs with 10 to 300 Microsoft 365 tenants in the US, UK, AU, NZ and EU.
**The problem:** Basic auth is disabled by default for existing tenants at the end of December 2026 <https://www.itelio.com/en/microsoft-message-center/MC786329>. Microsoft's usage report is a per-tenant CSV button with no documented API <https://learn.microsoft.com/en-ie/exchange/monitoring/mail-flow-reports/mfr-smtp-auth-clients-report>; Graph sign-in logs need Entra P1 <https://learn.microsoft.com/en-us/graph/api/resources/signin?view=graph-rest-1.0>. Printer vendors often have no fix <https://office365itpros.com/2026/01/29/smtp-auth-basic-retirement/>.
**Why now:** end-December switch-off; the report keeps only 90 days, so data must be pulled now.
**Market analysis:**
- Market size: every existing tenant; MSP count reachable unknown
- Money flowing: MSPs sell "Basic Authentication Review" services <https://allitservices.com.au/microsoft-is-switching-off-basic-auth-for-scan-to-email-in-december-what-australian-businesses-must-fix-now/>; relays at $79/month shown <https://www.smtp2go.com/blog/the-end-of-microsofts-basic-authentication-for-smtp-auth>
- Competitors: Augmentt (price unknown, shows status, not usage) <https://www.augmentt.com/solutions/exchange/>; free scripts (config only or need P1); CIPP coverage unknown
- The gap: usage-to-device map across tenants without P1, plus ranked fixes
**Our angle:** usage evidence, not a status flag; runs locally so no tenant data leaves the MSP.

**Our angle:** multi-state, drop-in, no health claims, no legal advice.
**Build difficulty:** Medium · 12 to 15 engineer-days · TS/Python SDK plus small API · hardest: crisis detection with few misses
**Where to publish and sell:** own site with Polar; npm/PyPI; Product Hunt, Indie Hackers

**Risks:** small buyer pool · vetting adult apps for Polar · crisis false negatives.
**Confidence:** Low-medium.
