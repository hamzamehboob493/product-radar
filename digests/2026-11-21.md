### 1. Microsoft To Do tenant migrator · 63/100 · WATCHLIST (card 1 of 2)
**Track:** Bigger build (build 1 to 4 weeks, launch by day 30) · **Sector:** Productivity / MSP
**What it is:** An admin-consented web app that moves every user's To Do lists in a Microsoft 365 tenant into Planner, rebuilding shared lists as group plans, with an audit CSV.
**Who pays:** MSPs with 5 to 100 client tenants, and IT admins at 50 to 2,000-seat firms. US, UK, EU, AU, NZ.
**The problem:** "Existing To Do tasks and lists will not migrate to Planner." Shared-list members "will not transfer". Microsoft's export "does not mean that the content can be imported". <https://support.microsoft.com/en-us/planner/to-do-to-planner>
**Why now:** Announced 19 Nov. Apps retire 30 Jun 2027. <https://windowslatest.com/2026/11/19/microsoft-is-killing-to-do-and-telling-you-to-choose-another-app-after-it-reportedly-paid-up-to-200-million-for-wunderlist-and-killed-it-for-to-do>
**Market analysis:**
- Size: M365 has 450M+ commercial seats <https://office365itpros.com/2026/01/30/microsoft-fy26-q2-results/>. To Do user count unknown
- Money: paid migration tools are a proven category. Nobody sells a To Do move yet
- Competitors: ShareGate "does not support Tasks, To Do" <https://help.sharegate.com/en/articles/10236208> · TickTick import is one user at a time, free to $49.99/yr · Zenkit drops shared lists and steps · free GitHub exporter needs a token per user
- The gap: no tenant-wide bulk move found
**Our angle:** One consent per tenant, every user, shared lists kept, at an MSP price.

### 2. LS Licence Bridge · 61/100 · WATCHLIST (card 1 of 2)
**Track:** Micro (build ≤5 days, launch by day 10) · **Sector:** Developer tools · Returning (was 70)
**What it is:** A hosted API with Lemon Squeezy-shaped licence endpoints. It imports keys and activations and runs on any payment provider, Polar first.
**Who pays:** Solo and small desktop, plugin and WordPress sellers worldwide whose shipped apps call LS licence checks.
**The problem:** LS payments stop 31 Mar 2027. Managed Payments excludes "license keys", and "APIs and webhooks do not redirect automatically". <https://docs.lemonsqueezy.com/migration>
**Why now:** Stripe's tools arrive 2 Dec. LS says start by mid-January.
**What changed since 19 Nov:** Dodo (16 Nov), LicenseManager.dev (17 Nov) and Freemius (18 Nov) now import LS keys. An MIT self-hosted "API-compatible" clone, Keypost, appeared 18 Nov (completeness unknown).
**Market analysis:**
- Size: LS merchants "thousands" (no exact count). Licence-key users unknown
- Money: 3 vendors built import within 72 hours. That is a demand signal, not revenue
- Competitors: Dodo CLI, free with Dodo, but "customers must re-activate" <https://dodopayments.com/blogs/lemon-squeezy-shutting-down-migrate-to-dodo-payments> · LicenseManager.dev keeps keys, app code must change <https://licensemanager.dev/blog/lemon-squeezy-shutting-down> · Keygen Dev free to 100 users <https://keygen.sh/pricing> · Polar native keys, no import, no deactivate API
- The gap: hosted response compatibility plus kept activations
**Our angle:** No app update, no re-activation, any provider.
